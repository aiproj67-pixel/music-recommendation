# Music Recommendation System

## Project Overview
This is an Artificial Intelligence project developed
using Python and a CSV dataset.

The system recommends songs based on the user's
favourite music genre, artist, or song.

## Objectives
- To understand recommendation systems.
- To use CSV files for storing music information.
- To implement basic content-based filtering.
- To practise Python programming.
- To learn how to use GitHub.

## Technologies Used
- Python
- CSV dataset
- GitHub

## Project Files
- songs.csv: Contains song information.
- music_recommender.py: Python source code.
- README.md: Project documentation.

## How to Run
1. Install Python.
2. Download the project files.
3. Keep the CSV and Python files in the same folder.
4. Run:

   python music_recommender.py

## Recommendation Method
The program filters songs using genre, artist,
and song genre similarity.

## Conclusion
This project demonstrates how a simple music
recommendation system can be created using Python
and structured CSV data.
